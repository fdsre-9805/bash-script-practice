# Контрольная точка «Основы Bash-скриптов»

## Что делает скрипт

`project-helper.sh` автоматизирует подготовку папки нового проекта:

```text
создать папку проекта -> создать файлы -> проверить результат -> записать отчёт
```

1. Берёт имя проекта из первого аргумента. Если аргумента нет, спрашивает имя через `read`. Если имя пустое, выводит сообщение и завершается с кодом 1.
2. Создаёт папку `reports` для отчёта.
3. Создаёт папку проекта с подпапками `src`, `docs`, `data` и файлами `README.md` и `src/main.sh`.
4. Проверяет, что каждая подпапка создана.
5. Записывает отчёт в `reports/result.txt`: имя проекта, дата, результат проверки, список файлов проекта и их количество.
6. Показывает отчёт в терминале.

## Запуск

```bash
chmod +x project-helper.sh
./project-helper.sh demo-project
```

Без аргумента скрипт сам спросит имя проекта:

```bash
./project-helper.sh
```
